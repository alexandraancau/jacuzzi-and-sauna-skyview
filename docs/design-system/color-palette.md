# Color Palette

## Purpose

The Skyview color palette is designed to evoke calm, warmth and intimacy.

The palette should never feel cold, overly luxurious or visually noisy.

Every color exists to support one feeling:

**Unwind.**

---

# Design Principles

The interface should feel:

- Calm
- Warm
- Elegant
- Timeless
- Minimal

It should never feel:

- Loud
- Cold
- Over-decorated
- Corporate
- Futuristic
