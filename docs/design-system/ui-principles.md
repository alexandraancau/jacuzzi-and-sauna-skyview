# UI Principles

## Purpose

The Skyview interface should feel calm, intuitive and effortless.

Users should focus on the experience, not on the interface.

Every screen should reduce cognitive load and support the feeling of unwinding.

---

# Core Principles

Every interface should be:

- Calm
- Spacious
- Consistent
- Accessible
- Human

The UI should never compete with the photography.

---

# Layout

Create visual rhythm through generous spacing.

Guidelines:

- Maximum content width: 1200px
- One primary message per section
- Consistent spacing between sections
- Avoid visual clutter

Whitespace is part of the design.

---

# Cards

Cards group related content.

## Principles

- Large internal padding
- Rounded corners
- Soft shadows
- Warm Ivory background
- Clear visual hierarchy

Cards should feel lightweight and elegant.

Avoid heavy borders whenever possible.

---

# Buttons

Buttons should guide users naturally.

## Primary Button

- Signature Plum background
- Warm Ivory text
- One primary CTA per section

Examples:

- Book now
- Check availability

## Secondary Button

- Transparent background
- Graphite border
- Graphite text

Avoid placing multiple competing primary actions together.

---

# Typography

Typography should create calm.

- Comfortable line height
- Generous spacing
- Clear hierarchy
- Easy to scan

Never use excessive font weights or decorative text effects.

---

# Images

Photography tells the story.

Rules:

- Large imagery
- Natural lighting
- Authentic moments
- Minimal cropping

The interface should frame the photography, not overpower it.

---

# Animations

Motion should feel natural.

Guidelines:

- Slow
- Smooth
- Subtle
- Purposeful

Avoid:

- Bouncing effects
- Flashy transitions
- Distracting motion

Animations should support orientation, not entertainment.

---

# Forms

Forms should feel effortless.

Rules:

- One-column layout
- Clear labels
- Short forms
- Helpful validation
- Large touch targets

Users should never wonder what to do next.

---

# Icons

Icons support understanding.

They should be:

- Simple
- Consistent
- Minimal
- Secondary to text

Icons should never replace important labels.

---

# Navigation

Navigation should feel invisible.

Principles:

- Simple structure
- Clear hierarchy
- Persistent booking action
- Minimal number of links

The goal is confidence, not exploration.

---

# Accessibility

Every interface should be usable by everyone.

Requirements:

- WCAG AA minimum
- Visible keyboard focus
- Sufficient color contrast
- Accessible touch targets
- Never rely on color alone

---

# Responsive Design

Design for mobile first.

The experience should remain consistent across:

- Mobile
- Tablet
- Desktop

Layouts may change.

The feeling should not.

---

# Design Checklist

Before approving any screen, ask:

- Is it easy to understand?
- Does it feel calm?
- Is the content easy to scan?
- Does the photography remain the hero?
- Does this help guests unwind?
